Un **Signal** Angular permet de gérer un état réactif dans l’application : lorsqu’une valeur change, l’interface peut se mettre à jour automatiquement. Cependant, cette valeur est stockée en mémoire et disparaît généralement lorsque la page est rechargée. À l’inverse, le **localStorage** permet de conserver des données dans le navigateur de manière persistante, même après un rechargement ou la fermeture du navigateur. Les deux peuvent donc être complémentaires : le Signal gère la réactivité de l’application, tandis que le localStorage assure la persistance des données.

Dans le cas de l'application, on utilise un signal pour le currentUser afin de pouvoir mettre à jour dynamiquement la page lors de la récupération de l'utilisateur. En revanche, le JWT est stocké dans le localStorage car on ne vas jamais l'afficher à l'écran et qu'on a besoin de le conserver pour les requêtes futures.
